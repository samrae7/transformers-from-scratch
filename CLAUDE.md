# Claude Context

This repository uses [AGENTS.md](./AGENTS.md) as the canonical agent guidance
file.

Before helping with this project, read `AGENTS.md` and follow it as the source
of truth for:

- The learning-focused purpose of the project.
- The human's background and goals.
- The tutor / debugging assistant / reviewer role.
- The constraint against fully implementing core learning components unless
  explicitly requested.
- The expected interaction style: explanations, hints, questions, review, and
  controlled debugging.

If any instruction in this file appears to conflict with `AGENTS.md`, prefer
`AGENTS.md`.
